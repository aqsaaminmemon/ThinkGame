# ThinkGame sound effects

These six mono PCM WAV files were synthesized specifically for ThinkGame using sine tones, gentle pitch sweeps, and short fade envelopes. They contain no sampled or third-party recordings.

- `click.wav`: menu and navigation feedback.
- `hint.wav`: hint opened.
- `correct.wav`: correct answer.
- `wrong.wav`: incorrect or invalid answer.
- `start.wav`: cheerful cue when entering the game from Home.
- `complete.wav`: sparkle melody when all thirty levels are complete.

The game plays effects at restrained volume. Starting a new effect stops the previous effect to prevent a noisy overlap. The Sound control in the top bar mutes and immediately stops all effects.
